# 직접 승인(--approve)과 승인자 id 안내

## 바뀐 것
- 승인 창구의 운영 주체는 incident-recovery로 정리되었다.
- narrator의 `--approve`(기본값 끔)는 picasso 참조 실행기 시연용 잔재로 보는 것이 조직 합의다.
- narrator는 자기 id `narrator-1`을 유지한다.
- recovery가 `recovery-1`로 전환한 뒤에는 recovery에서 `narrator-1`을 빌려 쓰지 않는다.

## 받는 쪽이 정할 것
- `--approve`를 삭제할지, 또는 문서상에 잔재로 명시할지는 incident-narrator 가 결정한다(자문은 문서로 적는 쪽을 권함).
